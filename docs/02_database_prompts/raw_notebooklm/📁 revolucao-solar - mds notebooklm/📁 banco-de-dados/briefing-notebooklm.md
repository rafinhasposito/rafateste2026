# BRIEFING PARA NOTEBOOKLM — Modificadores de Personalização

## CONTEXTO

Você vai gerar modificadores de personalização para um aplicativo de Revolução Solar.
Já existe um texto-base das 12 casas (arquivo guia-casas-revolucao.md em anexo).
Agora preciso gerar 5 lotes de modificadores que vão personalizar esse texto-base
para cada usuário, com base em 5 filtros.

## TOM E ESTILO OBRIGATÓRIOS

- Prático, direto, sem jargão astrológico excessivo
- Focado em ação real e transformação concreta
- Empoderador, sem promessas vazias
- Com exemplos do cotidiano
- Máximo de 1 frase por bloco
- Use a segunda pessoa ("você")

## FORMATO DE SAÍDA

Markdown estruturado com `##` para cabeçalhos e `**negrito**` para rótulos.
Sem introduções, sem conclusões, sem comentários extras.
Apenas o conteúdo solicitado, pronto para conversão.
