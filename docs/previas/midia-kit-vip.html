1. Qual papel pedir na gráfica rápida?

Peça Couchê Fosco 300g ou 350g com Laminação Fosca (ou Soft Touch). Para o envelope, compre Envelope DL (11x22cm) em Papel Color Plus Preto (180g) — o Boarding Pass entra com folga milimétrica perfeita.

2. Truque da Raspadinha Dourada

O quadro do Código de Resgate no canhoto foi desenhado com 42×14 mm — medida exata dos adesivos de raspadinha dourada vendidos prontos no Mercado Livre/Shopee. Basta colar sobre o código impresso!

3. Toque Pessoal com Caneta Dourada

Clique no botão "✍️ À Mão" acima se quiser imprimir vários bilhetes iguais e escrever o nome de cada amigo à mão usando uma caneta gel metálica dourada (ex: Uni-ball Signo Noble Metal Gold).

4. Como exportar o PDF perfeito?

Clique em Imprimir / Salvar PDF (⌘P), escolha Salvar como PDF, tamanho A4, escala 100% (Padrão) e marque a opção "Gráficos de segundo plano" (Background graphics).
