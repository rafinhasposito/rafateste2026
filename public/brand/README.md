# Protocolo Solar - Brand Kit V2

Sistema aprovado:
- Paleta: B - Original refinada
- Display: Marcellus
- UI: DM Sans
- Assinatura: O GPS do seu novo ciclo.
- Símbolo: Sol central + roda das 12 Casas da Revolução Solar

Arquivos:
- `protocolo-solar-emblema-master.png`: arte-mestre aprovada, sem alterações.
- `protocolo-solar-simbolo-redondo.png`: recorte circular transparente.
- `protocolo-solar-simbolo-transparente-2048.png`: símbolo PNG transparente em alta resolução.
- `protocolo-solar-app-icon-1024.png`: base quadrada para o ícone.
- `protocolo-solar-logo-horizontal-4096.png`: assinatura horizontal transparente.
- `protocolo-solar-logo-horizontal-dark-4096.png`: assinatura horizontal sobre fundo oficial.
- `protocolo-solar-logo-vertical-2048.png`: assinatura vertical transparente.
- `protocolo-solar-logo-vertical-dark-2048.png`: assinatura vertical sobre fundo oficial.
- `protocolo-solar-wordmark-3000.png`: logotipo tipográfico transparente.
- `protocolo-solar-wordmark-dark-3000.png`: logotipo tipográfico sobre fundo oficial.
- `protocolo-solar-logo-horizontal.svg`: assinatura horizontal.
- `protocolo-solar-logo-vertical.svg`: assinatura vertical.
- `protocolo-solar-wordmark.svg`: logotipo tipográfico.
- `fonts/`: Marcellus e DM Sans oficiais, com licenças OFL.
- `brand-tokens.css` e `brand-tokens.json`: implementação.

Os PNGs já estão rasterizados com Marcellus e DM Sans corretas. Os SVGs preservam texto vivo e o aplicativo deve carregar as fontes incluídas antes de renderizá-los. Para impressão gráfica, converter o texto em curvas no software vetorial.
